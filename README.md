## 🎯 周报生成核心导向与 Prompt 指南 (Core Reporting Principles)

> 💡 **核心汇报原则：高调呈现战果与亮点，战略包装卡点与行动。优先放大做得好的地方，让管理层第一眼看到价值产出与业务冲劲！**

在每周根据数据解析并生成 HTML 周报时，必须贯彻以下 5 大汇报心智法则：

### 1. 黄金首屏法则（亮点前置 · 战果最大化）
- **高调展示高光成就**：首屏「1分钟经营速览」与顶部横幅，优先用最显眼的视觉强化本周最牛的成果（如 **KA 大单突破**、**超大金额新签**、**标杆客户成功案例**、**多席位批量加购**）。
- **指标优先挑正向讲**：如果总成交金额亮眼，就突出大金额；如果金额稍逊但单量/线索转化率高，就突出高转化率与单量；始终挖掘当周数据中最亮眼、最有说服力的维度作为主推指标。

### 2. 蓄水池造势法则（高意向待落袋金额前置）
- **展现未来确定性与业绩底气**：除了已落袋业绩，必须把正在审批、排期打款、合同盖章中的**“准业绩”**做成显眼的重点卡片（如 `锁定待落地高意向 ¥37,040`）。
- **向管理层传达**：“本周虽然成交了近 4 万，但我们账面还锁定了 3.7 万即将落地，下周大盘稳如磐石！”

### 3. 卡点转化包装法则（不叫“问题”，叫“战略攻坚破局点”）
- **避免负向抱怨或被动陈述**：遇到续约客单低、未达标、未接电话多等情况，绝不生硬罗列为“失败”或“差错”。
- **包装为主动的战略战役**：
  - ❌ *“本周续约客单价很低，很多大客户未续费流失严重。”*
  - ✅ *“下周破局战役：针对本季度到期大客户，**全面主动启动放价 S0 特惠策略**，精准挽回存量并锁定长期生命周期！”*
  - ❌ *“外呼次数太少，存在很多未回访漏单。”*
  - ✅ *“外呼精细化提效：重点攻坚上午 9:30-11:30 黄金触达时段，建立未接当日清零闭环机制。”*

### 4. 深度洞察与标杆复制法则
- **从数据提炼经验**：在通话质检与客户跟进中，重点提取 1-2 个成单拆解范例（如东莞康丽化妆品 90分 示范通话），体现专业销售能力与方法论沉淀，向团队和领导展示“可复制的成功打法”。

### 5. 视觉与动线心智设计
- **视觉对比烘托**：优秀的指标用清新绿（`--success`）加粗放大，战略待落地大单用高亮卡片包围，让好数据在视觉上具有压倒性优势。
- **紧凑高管摘要**：提供 30 秒读懂的速览卡片，确保即使领导没时间看完长表格，也能在 10 秒内留下“业务有突破、后劲很充足、下周有思路”的积极印象。

## 📁 规范项目结构

```text
arya-weekly/
├── index.html                           # 门户主页（始终重定向或展示最新一期周报）
├── reports/                             # 历期 HTML 周报存放目录
│   ├── index.html                       # 历期周报归档索引页
│   └── 2026-08-31_2026-09-06.html       # 具体某一期的周报 HTML
├── data/                                # 原始数据归档目录（一期一个独立文件夹）
│   ├── README.md                        # 数据结构与重命名规范说明
│   └── 2026-08-31_2026-09-06/           # 单期周报的多源数据包
│       ├── crm_weekly_export.xlsx       # CRM 经营主数据
│       └── ...                          # (可选其他数据：财务流水、大客进度、随手记等)
└── scripts/                             # 自动化解析与构建脚本
    └── generate_report.py               # 周报构建辅助工具
```

## 🚀 每周更新流程与多文件规划
1. **提供多源数据**：
   - 可以在根目录或 `data/` 下直接放入当周的一个或多个原始数据文件（如 CRM 导出表、大客户跟进表、财务流水或说明文档）。
2. **自动归档与重命名**：
   - 系统会自动创建当周专属文件夹 `data/YYYY-MM-DD_YYYY-MM-DD/`，并将文件规范化重命名（如 `crm_weekly_export.xlsx`、`high_intent_deals.xlsx` 等）。
3. **生成独立周报**：
   - 遵循上述《核心汇报原则》，自动提取提炼各文件多维数据，生成对应 `reports/YYYY-MM-DD_YYYY-MM-DD.html`。
   - 自动在顶栏下拉框及主页更新导航与链接。
4. **推送到 GitHub**：
   - 提交推送后，GitHub Pages 自动部署上线。
